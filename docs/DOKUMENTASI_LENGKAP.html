1. Gambaran Umum Project
OVERVIEW

IderKopi Absensi adalah platform absensi mobile internal berbasis Flutter (Android, iOS, Web) dan Backend Go/Fiber (PostgreSQL 16) yang dibangun untuk mengelola presensi harian seluruh staf operasional dan admin IDER KOPI. Setiap transaksi presensi diverifikasi secara otomatis berbasis koordinat lokasi GPS (server-side & client-side geofencing radius 150 meter) serta foto selfie kamera depan yang terenkripsi.

Fitur & Nilai Utama Platform (v2.0.0+1)
  • Geofencing Server & Client (150 m): Kalkulasi rumus Haversine real-time untuk memvalidasi posisi karyawan terhadap outlet aktif.
  • Verifikasi Selfie & Olah Gambar Client-Side: Pengambilan foto selfie via kamera depan dengan kompresi otomatis (<250 KB) sebelum diunggah.
  • Arsitektur Offline-First (SQLite + Queue): Karyawan tetap dapat melakukan presensi saat internet terputus; data disimpan lokal di SQLite dan otomatis disinkronkan via workmanager saat koneksi pulih.
  • Keamanan Token & Idempotensi: Enkripsi JWT di flutter_secure_storage, auto-refresh token 401 interceptor, serta header client_request_id untuk mencegah duplikasi absensi.
  • Portal Multi-Role: Antarmuka khusus Karyawan (presensi, jadwal shift, cuti, KPI, rekap) dan Dashboard Admin (audit lokasi, verifikasi, manajemen outlet).

6. Panduan Penggunaan Halaman & Screenshot Resmi
SCREENSHOTS & MANUAL
Halaman 01 · Autentikasi
Login Karyawan
Halaman gerbang utama untuk masuk ke sistem absensi menggunakan email terdaftar dan password. Memiliki validasi input real-time dan enkripsi token.
  • Input email terdaftar dan password akun.
  • Verifikasi JWT token via Go Fiber Backend API.
  • Auto-redirect ke /change-password bila login pertama kali.
  • Penyimpanan Token aman di Android Keystore / iOS Keychain.
Halaman 02 · Dashboard Utama
Beranda Karyawan
Pusat kontrol harian karyawan untuk melakukan Check-In / Check-Out, melihat status shift aktif, outlet penugasan, dan ringkasan kehadiran.
  • Menampilkan nama karyawan, outlet aktif, dan jam shift harian.
  • Tombol aksi cepat Check-In / Check-Out dengan status warna.
  • Badge indikator antrean sinkronisasi offline (Pending Sync).
  • Status kehadiran hari ini real-time dari server.
Halaman 03 · Absensi Verifikasi
Kamera Selfie & Validasi GPS
Antarmuka verifikasi presensi yang mengambil foto selfie wajah karyawan dan menghitung jarak radius koordinat GPS dari lokasi outlet.
  • Pengambilan foto wajah presisi tinggi via kamera depan.
  • Perhitungan otomatis jarak Geofence (Batas < 150 meter).
  • Kompresi foto client-side otomatis < 250 KB.
  • Tombol submit presensi dengan pengiriman client_request_id.
Halaman 04 · Audit Kehadiran
Riwayat Absensi Karyawan
Daftar rekaman riwayat kehadiran karyawan yang menampilkan jam masuk, jam pulang, foto selfie, lokasi GPS, dan status keterlambatan.
  • Filter pencarian berdasarkan bulan dan tahun.
  • Status berwarna: Tepat Waktu (Hijau), Terlambat (Kuning), Cuti (Biru).
  • Detail foto selfie dan rincian koordinat lokasi saat absen.
  • Dukungan caching SQLite saat perangkat offline.
Halaman 05 · Manajemen Akun
Profil Karyawan
Halaman rincian data diri karyawan, informasi kode staf, brand outlet penugasan, ubah password, dan opsi keluar akun (logout).
  • Informasi Kode Karyawan (contoh: IKI0013) dan Brand (iderkopi / iderpoint).
  • Navigasi ubah password keamanan akun.
  • Informasi versi aplikasi Flutter (v2.0.0+1).
  • Tombol Logout aman dengan pembersihan token JWT & cache.
Halaman 06 · Portal Pengawas
Login Portal Admin
Halaman khusus otentikasi administrator untuk masuk ke portal pengawasan dan manajemen outlet presensi IDER KOPI.
  • Masuk menggunakan email admin (admin@iderkopi.com).

  • Akses penuh ke dashboard monitoring outlet dan audit tim.

  • Kartu ringkasan total hadir, terlambat, izin/cuti, dan alpa harian.

7. Kontrak REST API Backend Go/Fiber
REST API CONTRACT

Seluruh komunikasi Flutter Mobile dengan Backend Go Fiber mengacu pada base URL /api/v1 dengan format envelope standar JSON: {"success": true, "data": ..., "message": "...", "error": null}.

Method Endpoint Path Auth Header Fungsi & Keterangan Response
POST/api/v1/auth/loginNoneAutentikasi email & password. Mengembalikan Access JWT + Refresh Token.
POST/api/v1/auth/refreshNoneMenerbitkan Access Token baru menggunakan Refresh Token yang valid.
GET/api/v1/auth/meBearer TokenMengembalikan data profil pengguna aktif dan flag must_change_password.
POST/api/v1/auth/change-passwordBearer TokenMengubah password akun dan mereset seluruh sesi refresh token aktif.
GET/api/v1/employees/meBearer TokenMengambil detail data karyawan, kode staf, dan penugasan brand.
GET/api/v1/outletsBearer TokenMengambil daftar outlet aktif beserta koordinat latitude, longitude, & radius.
POST/api/v1/attendance/selfieBearer TokenUpload foto selfie multipart file. Mengembalikan storage key / URL foto.
POST/api/v1/attendance/check-inBearer + Client IDTransaksi check-in dengan validasi geofence server dan header client_request_id.
POST/api/v1/attendance/check-outBearer + Client IDTransaksi check-out absensi harian dengan header client_request_id.
GET/api/v1/attendance/historyBearer TokenMengambil riwayat absensi harian karyawan berfilter bulan/tahun.
GET/api/v1/kpi/meBearer TokenMengambil nilai dan performa Key Performance Indicator (KPI) karyawan.

A. Perintah Testing & Static Analysis

Sebelum melakukan pembuatan rilis aplikasi, jalankan seluruh pengujian otomatis berikut untuk memastikan tidak ada kesalahan regresif:

1. Flutter Static Analysis:

flutter analyze (Hasil: No issues found!)

2. Flutter Unit & Widget Testing:

flutter test (Hasil: 150 / 150 Tests Passed)

3. Backend Go Unit Testing & Vet:

cd auth-backend && go vet ./... && go test ./... (Hasil: All Packages Passed)

B. Perintah Build Release APK

Gunakan perintah Flutter CLI berikut untuk mengkompilasi APK rilis dengan konfigurasi endpoint production API:

Build Production APK (`--flavor prod`):

flutter build apk --flavor prod --dart-define=CUSTOM_API_BASE_URL=http://100.90.46.31:2026/api/v1
