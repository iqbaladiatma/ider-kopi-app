# Roadmap

## Selesai

- Single custom Go API dan PostgreSQL.
- JWT login/refresh dan role barrier.
- Attendance mobile, selfie, geofence, outlet, holiday, shift, leave, recap, KPI.
- SQLite cache, offline queue, idempotency, dan background sync.
- Analyzer dan automated test baseline.

## Berikutnya

- Isi outlet dan koordinat produksi yang tervalidasi melalui admin.
- Tambah integration test authenticated dengan akun fixture staging.
- Observability untuk queue sync dan selfie storage.
- TLS/domain resmi untuk trafik di luar private Tailscale.
- Uji perangkat fisik Android/iOS untuk GPS, kamera, dan background execution.
